# 答案隔离—校正模块（内部校验）

1. 将文章、题干和选项放入分析上下文，明确隐藏答案字段。
2. 在不知道答案的前提下先建立证据句、推理链、置信度和可能反例；不单独生成或向用户展示“模型盲答选项”。
3. 完成证据分析后才加载官方/高置信度答案，用于校正证据链，而不是把答案倒灌进前面的分析。
4. 对正确、错误和证据不足分别记录；用户没有要求作答训练时，不要求用户提交选项。
5. 分歧时比较原文、官方答案和多个解释，保留争议日志；争议题不得作为高置信度模板。

该流程用于降低答案锚定偏差和发现难题，不表示模型真的接受了参数训练；历史评测可以保存内部盲答记录，但不得在普通用户输出中泄露。
