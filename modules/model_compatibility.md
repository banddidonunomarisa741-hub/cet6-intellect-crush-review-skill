# 模型兼容性与能力评估

这份 Skill 的大部分能力来自路由、资料结构、答案隔离和复盘协议，不要求某一家模型的权重。模型选择要分成“能运行”和“能稳定达到目标质量”两件事。

## 最低运行条件

1. 能加载 `SKILL.md` 并按短命令选择模块；
2. 单次至少容纳一篇 CET-6 文章、题干/选项和当前模块说明；
3. 能读取本地 Markdown/JSON 或用户提供文件；
4. 最好支持网页检索、结构化输出和独立的答案隐藏回合；
5. 能在输出中保留证据位置、置信度和未决问题，而不是只给结论。

## 能力分层

### 基础任务（多数现代模型可用）

- 短命令路由；
- 中文式题干/选项压缩；
- 长难句主干、修饰、否定、比较和指代分析；
- 词表驱动的原创 15 选 10 生成；
- 错题归因和最小变式题。

### 进阶任务（需要模型 + 工具 + 协议）

- 隐藏答案后的盲答与答案核对；
- 10 空/15 选项的唯一性审计；
- 跨年份题型标签一致性；
- 外刊候选检索与来源降级；
- 统计蒙题策略的低权重表达。

### 高风险任务（不能只凭模型宣传）

- 断言“达到官方出题人水平”；
- 断言“等于真实阅卷人”；
- 对争议作文给出精确分数边界；
- 推断命题组内部决策或保密流程。

## 当前模型的合理预期

| 模型/平台 | 运行判断 | 需要注意 |
|---|---|---|
| Codex GPT-5.6 Sol | 适合完整流程和高难逆向 | 仍需盲测；长上下文不等于答案正确 |
| WorkBuddy | 若支持 Skill 路由、文件/网页工具和足够上下文，可运行核心流程 | “WorkBuddy”不是单一模型名称；必须记录实际模型、上下文上限和工具权限，不能仅凭平台名保证质量 |
| DeepSeek V4 Flash | 官方文档列出 1M 上下文、384K 最大输出、thinking、tool calls 和 Responses API，技术上足以运行核心流程 | 价格低不代表命题逆向或评分校准自动可靠；需用同一盲测集比较稳定性 |

## “可以运行”与“可以发布”不是同一个结论

对 WorkBuddy 必须记录它实际使用的模型、上下文上限、是否能读取本地文件、是否能检索网页、是否能执行多回合答案隔离。WorkBuddy 是产品/平台名称，不是一个固定智力等级；同名平台切换模型或关闭工具后，结果可能完全不同。

对 DeepSeek V4 Flash，若 API 实际返回的是 `deepseek-v4-flash-0731`（或供应商明确的同等版本），它可以承载本 Skill 的核心流程。但必须保留以下降级规则：无法独立隐藏答案时，不做“盲答准确率”宣传；无法访问来源时，关闭外刊溯源；唯一性审计失败时，把生成题标成草稿而不是练习题；作文分数只输出训练区间并提示人工复核。

建议把模型判定分成三档：

| 档位 | 证据门槛 | 对外说法 |
|---|---|---|
| 可运行 | 能完成 20 个样本并保留答案、证据和失败日志 | “支持该模型运行核心功能” |
| 可训练 | 阅读证据句命中率 ≥ 80%，词表填空唯一性审计漏检 = 0，溯源误启用 = 0 | “适合个人训练；复杂题需复核” |
| 可发布 | 再加入跨模型回归、人类抽样复核和成本/延迟记录；作文/翻译与人评的一致性达到预设目标 | “在限定范围内发布”，仍不得称官方阅卷/命题等效 |

这些阈值是工程发布门槛，不是考试机构认证；如果样本量不足，应明确写“尚未评估”。

## 发布前最小基准

每个候选模型至少跑以下 20 个隐藏答案样本：

- 5 道同句细节题；
- 5 道跨句/跨段推断题；
- 5 篇词表驱动原创语篇填词；
- 5 个外刊溯源候选，其中至少 2 个应正确降级为 `not_found`。

记录：盲答准确率、证据句命中率、干扰项分类一致率、唯一性审计误报/漏报、溯源误启用率、输出长度和成本。没有这组结果时，只能说“可运行”，不能说“没有任何问题”。
