# 翻译训练模块

先读取 `human_rubric.md` 和 `translation_calibration.md`。逐层检查信息完整性、语义准确性、句法、时态、搭配、专名和中英表达差异；优先修复数字、否定、因果、比较、范围和时间等会改变信息的错误。对照官方六级翻译评分样卷时，给出证据和区间，不把参考译文当作唯一表达，也不把诊断维度误报成官方分项分数。

给出可解释的分步改写和二次练习；用户有合法批改图片时可使用 OCR，但标记 OCR 不确定项并保留人工复核入口。

若输出原创参考译文、范文指导或改写示范，读取 `personal_language_bank.md`。优先把当前题目能承载的用户 `active`／`recycle` 词句和近期句型自然嵌入；没有个人语言库时，挑选少量真正有迁移价值的表达并标记为“AI 推荐”。参考译文后附“英文表达 → 当前中文义项 → 句法角色/搭配 → 可替换表达”表；普通基础词不逐词注释。词句若会造成信息增删、语气改变、搭配不自然或超出六级语域，应标记 `not_inserted` 并解释原因。
