# Skill 质量审计模块

维护按年份和题型分层的答案隔离评测集。每次改动记录版本、输入材料、模型配置、答案准确率（仅内部）、证据定位准确率、考点标签一致性、变式题质量、作文/翻译反馈变化和失败案例；普通用户输出不展示模型的盲答选项。

作文/翻译新增人工校准记录：数据集来源、题型、评分者培训、评分者数量、盲评顺序、档次分歧、人工复核结果、模型置信度和最终版本。至少报告相邻档误差、加权 Kappa/一致率、区间覆盖率和按题型/年份分层的结果；平均相关系数不能单独证明达到人工阅卷水准。所有来源与许可状态登记在 `human-sources.json`。

发布前至少完成：答案揭示前后记录不可篡改；跨年份测试；外刊溯源无来源时正确降级；选项分布只作为低权重策略且不能覆盖文本证据；低置信度样本会提示人工复核；高难/争议题能自动进入三次训练队列。

个性化词句复用另做分层回测：记录候选条目是否被自然插入（insertion precision）、用户目标条目的实际复现率、中文义项/搭配注释正确率、`not_inserted` 的理由是否成立，以及用户在新题中独立迁移的成功率。按作文/翻译、主题、复用强度和条目状态分层；不得用“插入了更多高级词”或单次作文分数变化替代自然度和迁移效果。保留一小组未展示目标词句的隐藏题，检查 Skill 是否会凭空声称复用了用户语言库或把 AI 推荐误标为已掌握。

为主动寻找“Codex 也会错”的样本，额外建立对抗集：隐含推断、否定/范围词、跨段证据、近义改写、作者态度转折、例子功能和两个选项都部分正确的题目。对抗集不得被答案键泄漏；发现错误后保存内部答案隔离日志、校正证据和新的最小训练单元。

人工评分对照也要做盲测：先隐藏人工分数和样卷标签，让模型输出区间及理由，再揭示标签；不把公开可访问当成可再分发许可，不把一套样卷外推成官方阅卷器认证。
