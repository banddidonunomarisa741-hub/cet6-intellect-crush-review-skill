# 阅读逻辑模块

## 目标

- 解析文章主题、结构、论点、转折、因果、让步、对比和证据链。
- 对每道题标注题型、证据位置、所需推理操作和干扰项机制。
- 检查答案是否有充分文本支持、是否唯一，以及分析是否可能显著帮助作答。

## 分析顺序

先建立文章地图，再逐题处理；答案键只在证据链写完后用于校正。不要先看解析再反向寻找支持句。

1. 标出每段功能（背景、问题、论点、证据、转折、方案、结论）和段间关系。
2. 将题干改写成一个可检验命题，识别问的是事实、观点归属、推断还是功能。
3. 定位最短证据路径，保留必要短引文和段落/句子位置。
4. 对正确项做语义映射，对其余选项检查主体、范围、时间、因果、态度强度和证据缺失。
5. 做反事实检查：改变证据中的一个关键限定词，观察答案是否应当改变。

## 输出骨架

1. 文章地图
2. 题目—证据索引
3. 考点和逻辑判断点
4. 干扰项逐项排除
5. 可迁移训练点
6. 置信度、反例和未决问题
7. （仅用户调用时）中文式刷题、中文背景或蒙题弱决策

## 中文式刷题模式

仅当用户说“中文式”“中文极简”“中文化”或明确要求中文压缩时，减少词汇翻译，把工作重心转到；且必须放在英文证据分析之后：

- 题干和选项的命题关系用中文压缩成一句话；
- 标出关键长难句的主干、修饰范围、否定/比较/让步和指代；
- 把每个选项改写成可检验的中文命题，再回到英文原句核对；
- 解释“为什么这个选项看起来对但不成立”，而不是重复全文翻译。

中文只是中间表征，最终证据仍须回到英文原文；中文概括与英文句义冲突时，以英文句法和语义为准。
