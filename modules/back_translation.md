# 翻译回译训练

本模块用于 `翻译·回译训练`，在 `translation.md`、`human_rubric.md` 和 `translation_calibration.md` 的基础上，把信息保真、回译差异和英文自然度分成三层。回译是诊断工具，不是官方独立评分维度，也不是参考译文的替代品。

## 词汇提示开关

用户可选 `无提示`、`专名提示` 或 `教学提示`；未指定时使用“专名提示”。

- **无提示**：只提供中文原文，用于诊断真实水平。
- **专名提示（默认）**：仅标注难以凭语言规律推导、且译法需要稳定的文化专名或特殊词汇；普通词不提示。
- **教学提示**：补充少量关键词、搭配或句法方向，但不展示完整译句和参考译文。

所有提示必须标明是官方/权威译名、常见译法、语境候选还是模型建议；存在多个合理译法时不得伪装成唯一答案。

## 三层诊断

### 1. 信息单元

把中文原文拆成最小可核对单元：主体、动作、对象、数字/时间、否定、因果/转折、比较、范围、程度、文化专名和句间关系。用户初译后逐项标记：

- `preserved`：意义和关系保留；
- `weakened`：主要意思仍在，但程度、范围或细节减弱；
- `distorted`：意思或逻辑关系改变；
- `omitted`：漏译；
- `added`：加入原文没有且会改变意思的信息。

优先处理数字、否定、因果、比较、范围、时间和主谓关系，不用低价值小错淹没关键问题。

### 2. 回译差异

依据用户的英文译文生成尽量贴近其实际措辞和句法的中文回译，不得利用原始中文静默补回英文中缺失的信息。若同一模型同时看过原文，必须承认可能存在锚定偏差，并以逐词组证据说明回译来自用户英文的哪一部分。

将回译与原文对照，指出丢失、增添、强弱变化、指代变化和逻辑方向变化。回译能帮助检查信息是否保真，但一条生硬甚至不合搭配的英文也可能回译出正确中文，因此不能凭“回得来”判定英文合格。

### 3. 英文自然度

在不依赖回译结论的情况下，单独检查：句法完整性、时态/语态、主谓一致、词义与搭配、冠词和单复数、指代、句间衔接、语域及文化表达。把“信息正确但英文不自然”和“英文通顺但信息错误”分别报告。

## 完整闭环

中文原文 → 用户独立初译 → 信息单元核对 → 忠实回译与差异定位 → 英文自然度检查 → 用户自行二译 → 相邻官方档次校准 → 换材料迁移。

在用户完成二译前，默认不展示完整参考译文；需要直接纠正时仍遵循“定位 → 错误类型 → 最小提示 → 直接改法”的渐进顺序。最后可给一种原创参考译文和至少一种等价表达，但明确它们不是唯一答案。

训练记录至少保存：提示档位、信息单元状态、关键回译差异、自然度问题、用户二译修复情况和迁移题表现。只有在新材料中仍能保留信息关系并写出自然英文，才算发生迁移。
