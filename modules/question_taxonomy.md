# 题型与考点分类模块

## 标注顺序

先按题干动词和问句对象确定主标签，再按证据关系补充次标签。不要仅凭选项措辞或答案字母分类。

| 主标签 | 判定问题 | 常见证据 |
|---|---|---|
| 细节/事实 | 文中哪一句直接支持某个命题？ | 数字、定义、条件、事实陈述 |
| 主旨/标题 | 全文或段落共同回答什么？ | 首尾论点、重复概念、转折后结论 |
| 推断 | 原文没有原句复现，能否由多句共同推出？ | 因果、让步、对比、隐含前提 |
| 词义/指代 | 词在此处具体指什么？ | 邻句替换、代词先行词、语域 |
| 态度/观点归属 | 谁在说、作者是否认同？ | claim/report/argue、评价词、转折 |
| 例证/段落功能 | 例子、数据或引语为何出现？ | 论点—证据、问题—方案结构 |
| 逻辑关系 | 句间是什么关系？ | cause/effect、contrast、concession、condition |

## 伴随字段

每题至少记录：`主标签`、`次标签`、`证据位置`、`定位距离`（同句/邻句/跨句/跨段/全文）、`推理步数`、`题干范围`、`答案语气强度`、`干扰项变换`、`预计时间`、`难度`和`置信度`。难度由证据距离、竞争选项数量、逻辑操作和时间负荷共同决定，不用生词数量代替。

## 质量检查

- 题型说明必须能解释“为什么这道题需要这种证据”，不能只贴标签。
- 若题干问观点归属，分开记录“转述的他人观点”和“作者最终立场”。
- 若多个标签同样重要，保留一个主标签并解释次标签，不强行只选一个。
