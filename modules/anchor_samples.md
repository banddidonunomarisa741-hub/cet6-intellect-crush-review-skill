# 锚定样卷与图片批改资料

## 首选锚点：官方大纲内嵌样卷

官方 PDF 已公开可视化的六级作文与翻译评分样卷，包含 14、11、8、5、2 分档。Skill 使用时：

1. 先确认考试级别为 CET-6、题型和题目要求，再选择相同模块的锚点。
2. 先独立分析用户文本，记录初始档次和证据；不要先看“参考译文”或把样卷句子当模板答案。
3. 再按档次逐项对照：任务完成/信息覆盖、清晰度、连贯性、语言错误严重度、用词和句式成熟度。
4. 输出“当前文本证据 → 锚点特征 → 档次结论”的链条，并保留不确定项。

推荐定位（按 PDF 印刷页，不是 PDF 阅读器的 0 起始索引）：

| 资料 | 官方 PDF 印刷页 | 可用方式 |
|---|---:|---|
| 六级作文评分样卷 | 200–202 | 14/11/8/5/2 档人工锚点；比较切题、结构、语言错误和表达成熟度 |
| 六级翻译评分样卷 | 205–206 | 14/11/8/5/2 档人工锚点；比较信息覆盖、关系表达、句法、搭配和错误严重度 |

## 其他公开人类评分资料

可以搜索高校课程、教育考试机构和开放论文中的人工评分样本，但必须逐项登记：发布者、原始 URL、发布日期、评分者身份/培训、评分量表、是否双评或多评、许可（CC/开放获取/仅阅览）、下载时间和文件哈希。只要许可不明确，就不把全文或图片复制到仓库。

GitHub 对照项目（仅二手实现，不是官方背书）：

- <https://github.com/infometa/workbuddyskills/tree/main/skills/english-exam-writing-reviewer>：引用 2016 修订版大纲并设计可追溯输出，但仓库声明内容来自其他产品公开市场，不能直接再分发其中的第三方文本；许可证信息不完整，仅读取其结构思路。
- <https://github.com/sabercy1031/cet-writing-grader>：项目描述为 AI CET-4/CET-6 作文评分，未发现明确许可证或可核验人工样本；只能作为产品存在性线索。
- <https://github.com/Bogger111/AI_Essay-Translation_Grader>：开源 README 说明作文/翻译辅助批改，未给出 CET 人工校准数据；只能作为实现对照，不能证明评分有效性。

公开研究可以补充“如何做人工对照”的方法，但不能替换 CET-6 样卷。例如 [Empirical Study of Large Language Models as Automated Essay Scoring Tools](https://arxiv.org/abs/2401.03401)、[Can Large Language Models Automatically Score Proficiency of Written Essays?](https://arxiv.org/abs/2403.06149) 和 [Are Large Language Models Good Essay Graders?](https://arxiv.org/abs/2409.13120) 都使用人类分数或公开 AES 数据讨论一致性、反馈价值和误差。它们的考试、数据集和模型版本不同，Skill 只借鉴盲评、分层测试和误差报告方法。

截至本次核验，没有找到可确认“允许再分发、含真实 CET-6 手写答卷及逐份人类分数/批注”的开放数据集。官方 PDF 样卷是排版后的评分锚点，不应在文档中误称为“现场阅卷照片”。一旦用户提供有权使用的批改图片，才进入视觉 OCR 与人工标签校准流程。

## 图片和 OCR 纪律

- 图片样卷用于视觉核验和 OCR，仓库默认只保存 URL、页码、SHA-256、OCR 摘要、许可状态和必要短引文。
- 不抓取登录后资源、不绕过反爬、不批量转载教辅扫描件；若用户提供自己拥有权利的图片，可在其本地工作区分析。
- OCR 可能误读手写、标注和分数；视觉证据与文本抽取冲突时，标记 `ocr_uncertain`，不得静默修正。
- 任何样卷图片要进入公开发布包，必须先确认明确的再分发许可；官方网页“可公开访问”不等于自动授予 CC 许可。
