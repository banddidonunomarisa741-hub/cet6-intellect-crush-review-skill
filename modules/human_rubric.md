# 人类评分标准与证据层级

本模块是作文和翻译评分的根规则。它解决的是“怎样逼近人工阅卷的一致性”，不是把模型宣称为官方阅卷员。

## 一手标准

唯一的根评分源是中国教育考试网公开的《全国大学英语四、六级考试大纲（2016 年修订版）》：

- PDF：<https://cet.neea.edu.cn/res/Home/1704/55b02330ac17274664f06d9d3db8249d.pdf>
- 官方入口：<https://cet.neea.edu.cn/html1/folder/16113/1588-1.htm>
- 写作评分：第 4.1 节；翻译评分：第 4.2 节。
- PDF 印刷页 200–202：六级作文评分样卷；印刷页 205–206：六级翻译评分样卷。样卷按 14、11、8、5、2 分档排列。

## CET-6 作文

大纲规定六级作文 30 分钟、不少于 150 词、满分 15 分；作文使用总体印象（holistic）评分，档次为 14（13–15）、11（10–12）、8（7–9）、5（4–6）、2（1–3）。四、六级使用相同文字描述，但同档样卷按级别分别确定，因此六级只能与六级锚定样卷比较。

评分描述原文（不得改写成“错误数换算表”）：

| 档次 | 官方描述符 |
|---|---|
| 14 | 切题。表达思想清楚，文字通顺、连贯，基本上无语言错误，仅有个别小错。 |
| 11 | 切题。表达思想清楚，文字连贯，但有少量语言错误。 |
| 8 | 基本切题。有些地方表达思想不够清楚，文字勉强连贯，语言错误相当多，其中有一些是严重错误。 |
| 5 | 基本切题。表达思想不清楚，连贯性差，有较多的严重语言错误。 |
| 2 | 条理不清，思路紊乱，语言支离破碎或大部分句子均有错误，且多数为严重错误。 |

大纲同时明确：每次阅卷参照当次考试评分样卷，阅卷员经过培训后参照样卷评分。Skill 因此可以模拟“标准 + 锚定样卷 + 证据链”，但不能声称复现阅卷组内部的校准会议。

## CET-6 翻译

大纲规定六级汉译英段落主题涉及中国文化、历史和社会发展，难度略高于四级，30 分钟完成约 180–200 个汉字；满分 15 分，同样使用五档总体印象评分：

| 档次 | 官方描述符 |
|---|---|
| 14 | 译文准确表达了原文的意思。译文流畅，结构清晰，用词贴切，基本无语言错误，仅有个别小错。 |
| 11 | 译文基本表达了原文的意思。结构较清晰，语言通顺，但有少量语言错误。 |
| 8 | 译文勉强表达了原文的意思。译文勉强连贯，语言错误相当多，其中有一些是严重错误。 |
| 5 | 译文仅表达了小部分原文的意思。译文连贯性差，有相当多的严重语言错误。 |
| 2 | 除个别词语或句子，译文基本没有表达原文的意思。 |

翻译诊断可以拆成信息覆盖、意义准确、结构连贯、语言规范和策略，但这些是解释工具，不是官方独立分项。一个漏译的关键关系（因果、转折、范围、时间、数量）可能比多个表层小语法错误更影响档次。

## 证据层级

每个分数结论必须标记来源层级：

1. `official_rubric`：大纲原文、官方页、官方评分样卷。
2. `human_anchor`：官方样卷中对应档次的可观察特征；或有明确许可的人工作文数据及其评分协议。
3. `cross_sample_pattern`：多套公开样本中重复出现的模式，不能写成官方规则。
4. `model_judgment`：模型对当前作文/译文的推断，必须给置信度和证据句。

若来源只是教辅、博客、GitHub README 或未说明评分者资质的截图，标记为 `secondary_unverified`，只能用于发现候选规则，不能覆盖一手标准。

## 边界与人工复核

- CET 分数只能输出整数；档内可用 ±1，不能使用半分。
- 字数、内容缺失、书写可读性等影响须说明证据；没有公开硬阈值时写“酌情/待校准”，不要杜撰扣分公式。
- 处于相邻档之间、涉及题意是否完成、中文思维导致语用争议，或模型证据不足时，输出区间、低置信度和“需人工复核”，不要伪造精确度。
- AI 结果的正确定位是训练性评分器、错误诊断器和二稿比较器。它不能替代真实考试阅卷，也不能认证成绩。
