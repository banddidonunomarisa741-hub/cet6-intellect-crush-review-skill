# 碎片化出题模块

从已验证考点拆出最小可练单元，每次只练一个机制：

- 定位：给出题干关键词，要求找出支持句；
- 句法：标主干、修饰范围、否定/让步/比较和指代；
- 逻辑：判断因果、转折、条件或观点归属；
- 映射：把原文多个具体动作概括成选项的上位能力；
- 干扰项：只改变范围、主体、时间、因果方向或语气强度中的一项；
- 推断：要求由两句或两段共同推出，不允许添加常识前提。

## 生成协议

1. 读取原题已验证的主标签、证据距离和错误断点。
2. 先写目标机制和唯一证据，再写新材料，禁止只替换几个单词。
3. 生成 3–10 个单元时控制变量，每题只增加一个难度因素。
4. 做唯一性、证据支持、难度和原题记忆依赖检查。
5. 默认只展示任务和可选提示；用户明确“开始训练/我来答”后才进入作答回合。
