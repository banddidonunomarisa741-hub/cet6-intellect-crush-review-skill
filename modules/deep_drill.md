# 深度训练总控模块

当用户只提交一份六级试卷、一道阅读题或一句简短请求时，自动执行以下闭环，不要求用户再次解释目标：

1. 识别场次、卷号、板块和题号；缺失信息只询问无法从材料推断的最小问题。
2. 将答案索引暂时隔离，先从题干、原文和选项建立证据链、置信度和反例；不产生或展示模型的盲答选项。
3. 加载答案索引；优先官方/已授权答案，其次标记为公开参考答案；不得把未核验页面称为官方。
4. 对分歧题做强校正：原文证据、选项语义、答案来源、教辅/人工意见（若存在）分层记录。
5. 调用题型、逻辑断点和出题人视角模块，分析信息定位、干扰项、时间负荷和答案唯一性。
6. 将本题拆成 3–10 个最小训练单元；只有用户明确要求训练时才让用户作答，再揭示解析。
7. 记录错误类型和掌握度；未掌握的断点在短间隔后复现，连续掌握后转入跨文章迁移。

若材料是作文或翻译：先读取 `human_rubric.md`，再按类型读取 `writing_calibration.md` 或 `translation_calibration.md`；若用户要求范文/改写，或任务中已有个人词句，追加读取 `personal_language_bank.md`。使用官方样卷作锚点，输出训练性区间和证据链。若检测到人评与模型相差一个以上档次，自动降低置信度并进入人工复核，而不是擅自“裁决”人评。

## 输出顺序与停止条件

阅读任务默认按“结论 → 英文证据 → 题型/逻辑 → 干扰项 → 命题逆向 → 溯源状态 → 可选下一步”输出。只有命令中明确出现“中文背景/中文极简/中文式”，才在最后追加对应中文层；只有出现“训练/我来答/继续”，才进入用户作答回合。没有用户请求时不自动生成大批变式题、不自动讲蒙题统计。

每轮至少交付一个可复核结论和一个不确定性说明；若来源、答案或文本不完整，停止在证据边界，不用模型自信度补齐缺失事实。

默认输出短而密集：先给结论、证据和解释。中文式刷题只有在用户明确说“中文式/中文极简/中文化”或相应短命令时，放在其他分析之后输出；否则不要主动翻译或中文压缩。用户说“继续”“再来”“练到会”为继续当前队列；用户说“停止/总结”立即结束。
